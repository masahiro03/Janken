# Janken
Hunter x Hunter : カイトのクレイジースロット

## 課題内容（どんな作品か）
Hunter x Hunterが好きで、ピトー戦でカイトのクレイジースロットで勝つ可能性があったのかと思っており、考えてみました。
あの状況からカイトが勝てるとは思えませんが、爆弾で勝つという設定にしてみました。

## 工夫した点・こだわった点
UIなどはAIを活用させて頂きましたが、基本的な仕組みは自分で考えました。

## 難しかった点・次回トライしたいこと（又は機能）
じゃんけんやおみくじと同じ仕組みで、ランダムに出すので、そこの仕組みはあまり複雑にしておりません。

## フリー項目（感想、シェアしたいこと等なんでも）
AIに頼りすぎるとぱっと見、凄いものが出来ますが、理解が追い付かなくなるので、そこの塩梅が重要だと感じてます。
